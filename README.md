**Status**: ✅ Completed (study)  
**Completion Date**: 2025  
**Topics**: Networking fundamentals, routing and switching, network security

#### Network Fundamentals
Core networking concepts and technologies:
- TCP/IP protocol suite and OSI model
- IPv4 and IPv6 addressing and subnetting
- Network devices: routers, switches, wireless controllers
- Network topology architectures

[📂 View folder](./ccna)

- Static and dynamic routing (OSPF, EIGRP)
- VLANs and inter-VLAN routing

- Network segmentation and security best practices
