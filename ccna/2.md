## Introduction

A **Local Area Network (LAN)** connects devices that are located close to each other, typically within the same building or campus.  
A **Wide Area Network (WAN)**, on the other hand, connects devices that are far apart, often across cities or even continents.

In **wired LANs**, also known as **Ethernet LANs**, communication occurs through physical cables that connect devices.  
In contrast, **wireless LANs (WLANs)** use radio waves to establish links between nodes.

The term **Ethernet** refers to a family of LAN standards that define the **physical** and **data-link** layers of wired network communication.

---

## The Variety of Ethernet Physical Layer Standards

Ethernet can operate over several types of cabling:

- **Unshielded Twisted Pair (UTP)**: Uses copper wires twisted in pairs to transmit electrical signals.
- **Fiber Optic Cable**: Transmits data as light pulses through thin strands of glass or plastic fibers.

### Examples of Ethernet Types

| **Speed** | **Common Name** | **Informal IEEE Name** | **Formal IEEE Standard** | **Cable Type / Max Length** |
|------------|------------------|-------------------------|-----------------------------|------------------------------|
| 10 Mbps | Ethernet | 10BASE-T | 802.3 | Copper, 100 m |
| 100 Mbps | Fast Ethernet | 100BASE-T | 802.3u | Copper, 100 m |
| 1000 Mbps | Gigabit Ethernet | 1000BASE-LX | 802.3z | Fiber, 500 m |
| 1000 Mbps | Gigabit Ethernet | 1000BASE-T | 802.3ab | Copper, 100 m |
| 10 Gbps | 10 Gig Ethernet | 10GBASE-T | 802.3an | Copper, 100 m |

> **Tip:** Standards ending in **T** use **UTP (copper)** cabling, while those ending in **X** typically use **fiber**.

---

## Breaking Down a UTP Ethernet Link

A **UTP cable** contains several twisted pairs of copper wires. The **twisting** reduces **electromagnetic interference (EMI)**.  
- **10BASE-T** and **100BASE-T** require **two pairs** of wires.  
- **1000BASE-T** requires **four pairs**.  

Each wire pair has a distinct color code. Most Ethernet cables use **RJ-45 connectors** on both ends, each with **eight pins** that align with the eight wires inside the cable.

---

## UTP Cabling Pinouts for 10BASE-T and 100BASE-T

For proper data transmission, each wire inside the UTP cable must connect to the correct pin position on the RJ-45 connectors.

- **NIC transmitters** use pins **1 and 2**  
- **NIC receivers** use pins **3 and 6**  
- **Switches** do the opposite: transmit on **3 and 6**, receive on **1 and 2**

A **straight-through cable** connects pin 1 to pin 1, pin 2 to pin 2, and so on.  
It works when devices use **opposite pairs** for transmission and reception (e.g., PC to switch).

When connecting two devices that transmit on the same pins (like switch-to-switch), a **crossover cable** is required. This cable swaps the transmit and receive pairs so that pins 1/2 connect to 3/6 on the other end.

### Choosing the Right Cable Type

| **Use Case** | **Recommended Cable** |
|---------------|------------------------|
| Endpoints transmit on same pin pair | **Crossover Cable** |
| Endpoints transmit on different pin pairs | **Straight-through Cable** |

| **Transmits on Pins 1,2** | **Transmits on Pins 3,6** |
|----------------------------|----------------------------|
| PCs, Routers, Wireless APs | Switches, Hubs |

---

### Automatic Rewiring with Auto-MDIX

**Auto-MDIX (Automatic Medium-Dependent Interface Crossover)** allows devices to automatically detect the cable type and adjust the pin configuration if necessary.  
This eliminates the need to worry about straight-through or crossover cables — you can use either type.

---

## UTP Cabling Pinouts for 1000BASE-T

**Gigabit Ethernet (1000BASE-T)** uses all **four wire pairs**, allowing both ends to **transmit and receive simultaneously** on each wire pair.  
Pins **4-5** and **7-8** are added for the additional pairs, while the same pinout logic applies.

## Fiber Cabling Transmission Concepts

**Fiber optic cables** transmit light instead of electrical signals.  
They can be **multimode** (allowing multiple light paths) or **single-mode** (one precise light path for long-distance transmission).

| **Criteria** | **UTP** | **Multimode Fiber** | **Single-Mode Fiber** |
|---------------|----------|----------------------|------------------------|
| **Relative Cable Cost** | Low | Medium | Medium |
| **Switch Port Cost** | Low | Medium | High |
| **Max Distance** | 100 m | 500 m | 40 km |
| **Susceptibility to Interference** | Some | None | None |
| **Risk of Signal Eavesdropping** | Some | None | None |

## Sending Data in Ethernet Networks

An Ethernet frame consists of several fields, including headers and trailers that define structure and control.

| **Field** | **Bytes** | **Description** |
|------------|------------|-----------------|
| Preamble | 7 | Synchronization signal for devices |
| Start Frame Delimiter (SFD) | 1 | Marks the beginning of the frame data|
| Destination MAC Address | 6 | Identifies the recipient |
| Source MAC Address | 6 | Identifies the sender |
| Type | 2 | Specifies the higher-level protocol (e.g., IPv4, IPv6) |
| Data and Pad | 46–1500 | Contains data from upper layers (with padding if needed) |
| Frame Check Sequence (FCS) | 4 | Used for error detection |

**Header:** Preamble, SFD, Destination MAC, Source MAC, and Type  
**Trailer:** Frame Check Sequence (FCS)

---

### Ethernet (MAC) Addresses

A **MAC address** (Media Access Control) is a **48-bit identifier** (6 bytes), usually written as a 12-digit hexadecimal number.  
Each Ethernet device receives a **unique MAC address** from its manufacturer.

The first **3 bytes** represent the **Organizationally Unique Identifier (OUI)** assigned to the manufacturer, and the remaining **3 bytes** are unique to each device produced by that manufacturer (**device-specific identifier**).

| **Term / Feature** | **Description** |
|----------------------|-----------------|
| **MAC Address** | Defined by IEEE 802.3; unique 48-bit hardware address |
| **Ethernet / NIC / LAN Address** | Alternate terms for MAC address |
| **Burned-In Address** | The permanent address assigned by the manufacturer (MAC Address)|
| **Unicast Address** | Identifies a single device on the LAN |
| **Broadcast Address** | Represents all devices on the LAN |
| **Multicast Address** | Represents a group of devices on the LAN |

---

### Error Detection with FCS

The **Frame Check Sequence (FCS)** helps detect transmission errors.  
The sender calculates a checksum value using a mathematical formula and includes it in the frame.  
The receiver performs the same calculation and compares results to identify errors.

> ⚠️ **Note:** Ethernet detects but does not correct errors — corrupted frames are simply discarded without retransmission.

## Sending Ethernet Frames with Switches and Hubs

### Sending in Modern Full-Duplex LANs

In **half-duplex mode**, a device can either send **or** receive — not both simultaneously.  
In **full-duplex mode**, both operations can occur at the same time.  
Modern Ethernet networks (without hubs) operate in full-duplex mode by default.

---

### Using Half Duplex with Hubs

**LAN hubs** operate at the **physical layer**, repeating incoming electrical signals out of all other ports.  
If two or more devices send data simultaneously, a **collision** occurs and the signals become corrupted.

The **CSMA/CD (Carrier Sense Multiple Access with Collision Detection)** algorithm manages this process:

1. The device listens for a free channel.  
2. When the line is clear, it transmits the frame.  
3. If a collision occurs:  
   - A **jamming signal** notifies all devices.  
   - Each device waits for a **random time** before retrying transmission.  
   - The process repeats until successful.
