## Understanding IPv6 Address Configuration on Routers

### Static Unicast Address Configuration

#### Setting Up a Full 128-Bit IPv6 Address
To assign a full static IPv6 unicast address (either Global Unicast Address or Unique Local Address), use the following interface command:

```bash
ipv6 address <address/prefix_length>
````

#### Enabling IPv6 Routing

By default, Cisco routers have IPv4 routing enabled but not IPv6 routing.

* To enable IPv4 routing:

  ```
  ip routing
  ```
* To enable IPv6 routing:

  ```
  ipv6 unicast-routing
  ```

If you skip this step, the router will behave like a host — capable of sending IPv6 packets it generates but unable to route between interfaces.

#### Verifying IPv6 Configuration

Several familiar `show` commands can verify IPv6 settings:

* `show ipv6 interface brief` – Displays IPv6 addresses (without prefix length).
* `show ipv6 interface` – Provides detailed IPv6 configuration, similar to `show ip interface` for IPv4.

Note that `show interfaces` lists only IPv4 information, so use `show ipv6` commands for IPv6 details.

#### Automatically Generating Interface IDs (EUI-64)

Routers can auto-generate a unique interface ID (IID) using **EUI-64** with:

```bash
ipv6 address <prefix/prefix_length> eui-64
```

**How EUI-64 works:**

1. Split the 48-bit MAC address in half.
2. Insert **FFFE** between the two halves.
3. Invert the seventh bit of the first byte.

If the interface lacks a MAC address (e.g., serial links), the router uses the lowest-numbered interface’s MAC address.

#### IPv6 Address Attributes

Cisco IOS assigns short attribute codes to IPv6 addresses shown in `show ipv6 interface`.
Common attributes include:

| Attribute | Meaning                                                    |
| --------- | ---------------------------------------------------------- |
| **EUI**   | Address generated via modified EUI-64                      |
| **TEN**   | Tentative (under Duplicate Address Detection)              |
| **CAL**   | Calendared (time-based address, e.g., via SLAAC or DHCPv6) |
| **PRE**   | Preferred address for outgoing traffic                     |

### Dynamic IPv6 Address Configuration

Cisco routers can dynamically obtain IPv6 addresses through:

* **Stateful DHCPv6:**

  ```bash
  ipv6 address dhcp
  ```
* **Stateless Address Autoconfiguration (SLAAC):**

  ```bash
  ipv6 address autoconfig
  ```

## Special IPv6 Addresses Used by Routers

### Link-Local Addresses (LLAs)

#### What Are Link-Local Addresses?

Every IPv6-enabled interface must have a **Link-Local Address (LLA)**. LLAs are used for communication within a single link and are essential for protocols like **NDP** and **DHCPv6**.

**Key properties:**

* Represent a **single device** (unicast).
* Are **not forwarded** by routers beyond the local link.
* Are **self-generated** automatically.
* Serve as **next-hop addresses** in IPv6 routing.

#### Creating LLAs on Routers

Routers automatically generate LLAs using:

* Prefix: `FE80::/64`
* Interface ID: Generated via **EUI-64**

You can also manually configure an LLA:

```bash
ipv6 address <address> link-local
```

If omitted, IOS auto-generates one.

#### Using LLAs Without Global Addresses

The command:

```bash
ipv6 enable
```

activates IPv6 processing and assigns an LLA automatically without creating a GUA or ULA.
This setup is often used on WAN links or for dynamic routing protocol exchanges.

### IPv6 Multicast Addresses

IPv6 replaces Layer 3 broadcast with **multicast**, improving efficiency by targeting only relevant devices.

#### Common Multicast Groups

| Short Name    | Address           | Description                       | IPv4 Equivalent       |
| ------------- | ----------------- | --------------------------------- | --------------------- |
| All-nodes     | FF02::1           | All IPv6 nodes on the link        | 224.0.0.1             |
| All-routers   | FF02::2           | All IPv6 routers on the link      | 224.0.0.2             |
| All-OSPF / DR | FF02::5 / FF02::6 | OSPF routers / Designated Routers | 224.0.0.5 / 224.0.0.6 |
| RIPng         | FF02::9           | All RIPng routers                 | 224.0.0.9             |
| EIGRPv6       | FF02::A           | All EIGRPv6 routers               | 224.0.0.10            |
| DHCP Relay    | FF02::1:2         | DHCPv6 relay agents               | —                     |

You can view the multicast groups joined by an interface with:

```bash
show ipv6 interface <interface>
```

#### Multicast Address Scopes

| Scope              | Fourth Hex Digit | Definition    | Meaning                      |
| ------------------ | ---------------- | ------------- | ---------------------------- |
| Interface-Local    | 1                | Device        | Remains within the device    |
| Link-Local         | 2                | Device        | Confined to a single link    |
| Site-Local         | 5                | Router Config | Limited within a local site  |
| Organization-Local | 8                | Router Config | Spans an entire organization |
| Global             | E                | Global        | No boundaries                |

### Solicited-Node Multicast Addresses

IPv6 uses **Neighbor Discovery Protocol (NDP)** instead of ARP.
Each unicast IPv6 address has a corresponding solicited-node multicast address, beginning with `FF02::1:FF`.
This mechanism allows devices to discover each other efficiently at the MAC layer.

---

### Unspecified and Loopback Addresses

| Type            | Address | Purpose                                          |
| --------------- | ------- | ------------------------------------------------ |
| **Unspecified** | `::`    | Used when a host has not yet obtained an address |
| **Loopback**    | `::1`   | Used for testing the local IPv6 stack            |

---

### Anycast Addresses

**Anycast** addresses are shared among multiple routers providing the same service.
Routers advertise the same unicast address (usually with a `/128` prefix).
When packets are sent to that address, the network delivers them to the **nearest** router.

## IPv6 Addressing Configuration Summary

| Address Type                | Prefix/Notes   | Configuration Command                                                    |
| --------------------------- | -------------- | ------------------------------------------------------------------------ |
| Global Unicast              | Varies         | `ipv6 address <address/prefix>` or `ipv6 address <prefix/prefix> eui-64` |
| Unique Local                | FD00::/8       | `ipv6 address <address/prefix>` or `ipv6 address <prefix/prefix> eui-64` |
| Link-Local                  | FE80::/10      | `ipv6 address <address> link-local` or auto-generated                    |
| All-nodes Multicast         | FF02::1        | Auto-generated                                                           |
| All-routers Multicast       | FF02::2        | Auto-generated                                                           |
| Routing Protocol Multicasts | Varies         | Added automatically when protocol is enabled                             |
| Solicited-Node Multicast    | FF02::1:FF/104 | Auto-generated                                                           |
