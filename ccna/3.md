## Wide-Area Networks

A **Wide Area Network (WAN)** enables devices to communicate over long distances.  
WAN technologies define the **physical standards** and **data-link protocols** required for this type of communication.

---

## Leased-Line WANs

A **leased line** is a dedicated point-to-point connection that carries bits in both directions at a predetermined speed using **full-duplex** operation. Typically, it uses **two wire pairs**, one for each direction.

Leased lines are known by various names, including: leased circuit, serial link, point-to-point link, T1, WAN link, or private line.

### Data-Link Protocols for Leased Lines

Routers at each end of a leased line use data-link protocols such as:

- **HDLC (High-Level Data Link Control)**  
- **PPP (Point-to-Point Protocol)**

Both protocols ensure reliable delivery of data over the physical link. PPP is newer and offers additional features, but both share a similar frame structure.

**Comparison of HDLC/PPP Header Fields to Ethernet**

| HDLC & PPP Fields | Bytes | Ethernet Equivalent | Description |
|------------------|-------|------------------|-------------|
| Flag | 1 | Preamble, SFD | A recognizable bit pattern indicating the start of a new frame |
| Address | 1 | Destination Address | Identifies the destination device (less relevant in point-to-point topologies) |
| Control | 1 | N/A | No longer commonly used for router links |
| Type | 2 | Type | Specifies the Layer 3 packet encapsulated in the frame |
| FCS | 2 | FCS | Error detection field; the only trailer in the frame |

### Ethernet as a WAN Technology

Ethernet can also serve as a WAN medium. In this scenario:

- A router sends traffic out of the LAN toward a **Service Provider’s point of presence (PoP)**.
- The Service Provider uses an Ethernet switch to forward the traffic.  

This setup **logically** acts like a point-to-point connection between routers, even though the physical connection is through shared infrastructure.

## IP Routing

The **Internet Protocol (IP)** is responsible for moving packets from the source host to the destination host.

### Network Layer Routing Logic

If the source and destination are on different LANs:

1. The source sends the packet to its **default router** (also called default gateway).  
2. Each router forwards the packet according to its **routing table**, which contains IP networks and subnets.

### How Routers Use LANs and WANs

Internal steps for routing a packet:

1. Verify the frame using the **FCS field**; discard if errors are detected.  
2. Remove the data-link header and trailer to isolate the IP packet.  
3. Check the destination IP address against the routing table and select the best route.  
4. Encapsulate the IP packet with a new data-link header and trailer for the outgoing interface, then forward it.

Routers determine the appropriate **data-link address** using **ARP (Address Resolution Protocol)**, which dynamically maps IP addresses to MAC addresses on a LAN.

---

### How IP Addressing Supports Routing

Every interface that expects to receive IP packets must have an IP address.  
IP addresses are organized into **subnets** to allow routers to summarize routes and reduce the size of routing tables:

- Interfaces on the same physical network belong to the same subnet.
- Interfaces separated by at least one router belong to different subnets.

---

### How Routing Protocols Assist IP Routing

Routing protocols help routers share knowledge of network topology:

1. Each router adds directly connected subnets to its routing table.  
2. Routers inform neighbors about these routes.  
3. Routers learn additional routes from neighbors, typically recording the neighbor as the **next-hop router**.

If multiple routes exist to the same subnet, the router selects the **best route** based on metrics.

## Other Network Layer Features

### Domain Name System (DNS)

DNS allows the use of **hostnames** instead of IP addresses.  

Example workflow:

1. PC1 wants to reach Server1 using a hostname.  
2. PC1 queries a DNS server.  
3. The DNS server replies with Server1’s IP address.  

DNS information is distributed across many servers; no single server contains all mappings.

---

### Address Resolution Protocol (ARP)

ARP maps IP addresses to MAC addresses within a LAN:

1. A host or router broadcasts an **ARP request** for a given IP address.  
2. The device with the matching IP responds with its MAC address.  
3. The information is stored in the **ARP cache/table**.  

> To view the ARP table on a system, use: `arp -a`

---

### ICMP and the Ping Command

The `ping` command tests network connectivity using **ICMP (Internet Control Message Protocol)**:

1. Sends an **ICMP echo request** to the target IP.  
2. Receives an **ICMP echo reply** if the target is reachable.  

ICMP also defines several other messages to manage and control IP networks.
