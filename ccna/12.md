# Chapter 12 - Analyzing Classful IPv4 Networks
> **Source:** Adapted from *CCNA 200-301 Volume 1* by Wendell Odom  

When given an IP address and its corresponding subnet mask, you can determine several key details about the network, such as:  
- Its class (A, B, or C)  
- The default subnet mask  
- The number of **network bits** and **host bits**  
- The total number of **host addresses** in the network  
- The **network ID**  
- The **broadcast address**  
- The **first and last usable IP addresses** within that network  

Understanding these fundamentals is essential for IPv4 network design, subnetting, and troubleshooting.

---

## Classful Network Concepts

### IPv4 Network Classes and Their Characteristics

IPv4 addresses were originally divided into **five classes (A through E)**, each designed for specific purposes and network sizes.

| Class | First Octet Range | Purpose |
|:------|:-----------------|:---------|
| A | 1–126 | Unicast |
| B | 128–191 | Unicast |
| C | 192–223 | Unicast |
| D | 224–239 | Multicast |
| E | 240–255 | Reserved for experimental use |

---

### Class A, B, and C Comparison

| Property | Class A | Class B | Class C |
|:----------|:--------|:--------|:--------|
| **First Octet Range** | 1–126 | 128–191 | 192–223 |
| **Valid Network Numbers** | 1.0.0.0 – 126.0.0.0 | 128.0.0.0 – 191.255.0.0 | 192.0.0.0 – 223.255.255.0 |
| **Total Number of Networks** | 2⁷ - 2 = 126 | 2¹⁴ = 16,384 | 2²¹ = 2,097,152 |
| **Hosts per Network** | 2²⁴ - 2 = 16,777,214 | 2¹⁶ - 2 = 65,534 | 2⁸ - 2 = 254 |
| **Network Bits (Octets)** | 8 (1) | 16 (2) | 24 (3) |
| **Host Bits (Octets)** | 24 (3) | 16 (2) | 8 (1) |
| **Default Mask** | 255.0.0.0 | 255.255.0.0 | 255.255.255.0 |

> **Note:**  
> The address ranges beginning with **0** and **127** are reserved.  
> Additionally, some addresses within classes A, B, and C are also set aside for special uses such as private networks or loopback testing.

---

## Deriving the Network ID and Related Values

To calculate the **network ID**, **broadcast address**, and usable host addresses from an IP address, follow these steps:

1. **Identify the class** of the IP address based on its **first octet**.  
   - Class A: 1–126  
   - Class B: 128–191  
   - Class C: 192–223  

2. **Separate the network and host octets** according to the class.  
   - Example: Class B → first two octets for network, last two for hosts.

3. **Find the network ID:**  
   Replace all **host octets** with zeros.  
   - Example: `172.16.45.10` → `172.16.0.0`

4. **Find the first usable address:**  
   Add 1 to the last octet of the network ID.  
   - Example: `172.16.0.0` → `172.16.0.1`

5. **Find the broadcast address:**  
   Replace all **host octets** with 255.  
   - Example: `172.16.0.0` → `172.16.255.255`

6. **Find the last usable address:**  
   Subtract 1 from the broadcast address.  
   - Example: `172.16.255.255` → `172.16.255.254`

These calculations form the basis for subnetting, IP planning, and understanding how devices communicate within and between networks.
