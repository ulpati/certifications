# Chapter 14 - Analyzing Existing Subnets
> **Source:** Adapted from *CCNA 200-301 Volume 1* by Wendell Odom

## Defining a Subnet

A **subnet** is simply a subset of a classful IP network. It represents a smaller, manageable segment of a larger network.

Key characteristics of a subnet:

- Contains a **sequence of consecutive IP addresses**.  
- Includes **2^H total addresses**, where *H* is the number of host bits defined by the subnet mask.  
- Two special addresses within each subnet **cannot** be assigned to hosts:
  - **Subnet ID (Network Address):** the first address in the subnet, identifying the subnet itself.  
  - **Broadcast Address:** the last address in the subnet, used to send packets to all hosts within that subnet.  
- All addresses between these two values are **usable host addresses**.

---

### Subnet ID Concepts

| Concept | Description |
|:--|:--|
| **Definition** | A unique number that identifies the subnet |
| **Numeric Value** | The smallest (first) address in the subnet |
| **Literal Synonyms** | Subnet number, subnet address, prefix, resident subnet |
| **Common-Use Synonyms** | Network, network ID, network number, network address |
| **Typically Seen In** | Routing tables, network documentation |

---

### Subnet Broadcast Address

| Concept | Description |
|:--|:--|
| **Definition** | A reserved address used to deliver packets to all devices within the subnet |
| **Numeric Value** | The largest (last) address in the subnet |
| **Literal Synonyms** | Network broadcast |
| **Typically Seen In** | Calculations of address ranges within subnets |

## Analyzing Existing Subnets — Binary Method

### Finding the Subnet ID (Binary Method)

The subnet ID can be determined by applying the following rules:

- All addresses within a subnet — including the subnet ID, broadcast address, and host addresses — **share the same prefix bits**.  
- The **subnet ID** has all **host bits set to 0**.

**Process:**

1. Convert the subnet mask into prefix format to determine prefix length `/P` and host length `32 - P`.  
2. Convert the IP address to its **32-bit binary** representation.  
3. Copy the prefix bits (network + subnet part) from the IP address.  
4. Replace all host bits with **0s**.  
5. Convert the final 32-bit binary back into **decimal notation**, one octet at a time.

---

### Finding the Subnet Broadcast Address (Binary Method)

The process is nearly identical to finding the subnet ID, except that the **host bits are all set to 1** instead of 0.  
This results in the highest address in the subnet — the broadcast address.

---

### Shortcut for the Binary Process

**To find the Subnet ID:**

1. If the mask octet = **255**, copy the corresponding octet from the IP address.  
2. If the mask octet = **0**, write **0** for that octet.  
3. If the mask octet is neither 0 nor 255, use the binary process described above.

**To find the Broadcast Address:**

1. If the mask octet = **255**, copy the corresponding IP address octet.  
2. If the mask octet = **0**, write **255**.  
3. If the mask octet is neither 0 nor 255, use the same binary method.

## Analyzing Existing Subnets — Decimal Method

### Working with “Easy” Masks

The easiest subnet masks to analyze are:

- `255.0.0.0`  
- `255.255.0.0`  
- `255.255.255.0`  

**Finding the Subnet ID:**

1. If the mask octet = **255**, copy the corresponding IP address octet.  
2. If the mask octet = **0**, write **0**.  

**Finding the Broadcast Address:**

1. If the mask octet = **255**, copy the corresponding IP address octet.  
2. If the mask octet = **0**, write **255**.  

---

### Finding the Subnet ID — Difficult Masks

For masks that aren’t straightforward (e.g., `255.255.255.240`), use the **magic number** method.

**Steps:**

1. If the mask octet = **255**, copy the IP address octet.  
2. If the mask octet = **0**, write **0**.  
3. If the mask octet is neither:
   - Calculate the **magic number**: `256 - mask_octet`.  
   - Find the **subnet ID** value as the largest multiple of the magic number **that does not exceed** the IP address octet.

---

### Finding the Subnet Broadcast Address — Difficult Masks

**Steps:**

1. If the mask octet = **255**, copy the corresponding subnet ID octet.  
2. If the mask octet = **0**, write **255**.  
3. If the mask octet is neither:
   - Calculate the **magic number**: `256 - mask_octet`.  
   - Add the magic number to the subnet ID octet, then subtract 1:  
     **Broadcast Address = Subnet ID + Magic Number - 1**.

---

### Example — Magic Number Method

**IP:** 192.168.10.77  
**Mask:** 255.255.255.240 → Magic number = 256 − 240 = **16**

| Step | Result |
|-|-|
| Largest multiple of 16 ≤ 77 | **64** → Subnet ID = 192.168.10.64 |
| Broadcast = 64 + 16 − 1 | **192.168.10.79** |
| Host range | 192.168.10.65 – 192.168.10.78 |
