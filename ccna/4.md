## Cisco Switch Interfaces

Cisco LAN switches use interface IDs that include abbreviations depending on the supported speed and interface type.

| Speeds Supported | Common Name | Example Interface ID | Valid Abbreviations |
|------------------|-------------|----------------------|---------------------|
| 10 Mbps | Ethernet | Ethernet 0/0 | E0/0, Et0/0, Eth0/0 |
| 10/100 Mbps | Fast Ethernet | FastEthernet 0/1 | F0/1, Fa0/1 |
| 10/100/1000 Mbps | Gigabit Ethernet | GigabitEthernet 1/0/1 | G1/0/1, Gi1/0/1 |
| 1G / 2.5G / 5G / 10G | Multigigabit | TenGigabitEthernet 1/0/2 | T1/0/2, Te1/0/2 |

## Accessing the Cisco IOS XE CLI

You can access the Cisco switch **Command-Line Interface (CLI)** in several ways:
- **Console connection**
- **Telnet session**
- **Secure Shell (SSH)** connection

### User and Privileged (Enable) Modes

When a user first connects to a Cisco switch, they enter **User EXEC mode**.  
In this mode, you can execute basic commands and view limited information.

To run more advanced or configuration-related commands, you must switch to **Privileged EXEC mode** (also called **Enable mode**).

- If the command prompt ends with `>`, you are in **User mode**.  
- If it ends with `#`, you are in **Enable mode**.

**Mode transitions:**

| Action | Command |
|---------|----------|
| User → Enable | `enable` |
| Enable → User | `disable` |

Commands that can be used in either mode are known as **EXEC commands**.

---

### Password Security for Console Access

By default, Cisco switches allow console access without requiring a password.  
To improve security, passwords can be configured for both login and enable access.

**Useful Commands:**

- `show running-config` → Displays the current active configuration
- `hostname <hostname>` → Sets the switch’s hostname
- `enable secret <password>` → Defines the privileged (enable) password
- `line console 0`, `login`, `password <password>` → Sets a console password and enables login

### CLI Help Features

Cisco IOS provides built-in help options to make command usage easier.

| Command Example     | Description                                                 |
| ------------------- | ----------------------------------------------------------- |
| `?`                 | Lists all available commands for the current mode.          |
| `command ?`         | Shows possible parameters for that command.                 |
| `com?`              | Displays all commands that start with “com.”                |
| `command parm?`     | Lists all valid options starting with “parm.”               |
| `command parm<Tab>` | Autocompletes the word if only one match exists.            |
| `command parm1 ?`   | Displays the next set of parameters and their descriptions. |

When you type `?`, the help executes immediately — no need to press *Enter*.

Additionally, Cisco IOS maintains a **command history buffer** (default size: 10).
Use the **up/down arrow keys** to navigate through previous commands.

---

### The `show` and `debug` Commands

- The `show` command displays real-time operational information about the device, such as interface status or configuration details.

- The `debug` command provides live updates about ongoing switch operations, generating messages as events occur.

    ⚠️ Use `debug` with caution in production environments, as it can consume CPU resources.

### Configuring Cisco IOS Software

Entering **Configuration mode** allows you to modify the device’s active settings.
Changes take effect immediately and update the **running configuration file**.

**Mode transitions:**
| Action                 | Command              |
| ---------------------- | -------------------- |
| Enable → Configuration | `configure terminal` |
| Configuration → Enable | `end` or `Ctrl+Z`    |

Configuration mode contains several **submodes**, depending on what you are configuring:
| Action                        | Command Example           |
| ----------------------------- | ------------------------- |
| Enter Interface Mode          | `interface <type/number>` |
| Enter VLAN Mode               | `vlan <id>`               |
| Enter Console Mode            | `line console 0`          |
| Enter VTY Mode                | `line vty 0 15`           |
| Exit Submode                  | `exit`                    |
| End and Return to Enable Mode | `end` or `Ctrl+Z`         |

### Storing Switch Configuration Files

Cisco switches use four primary types of memory:

- **RAM/DRAM** – Used for active operations and stores the **running configuration**.

- **Flash Memory** – Contains the **Cisco IOS image** used at startup and can store other files.

- **ROM** – Holds the **bootstrap program**, responsible for loading the IOS image into RAM.

- **NVRAM** – Stores the **startup configuration**, loaded when the switch boots.

Cisco IOS organizes configuration commands into files:

- **running-config** – Stored in RAM; reflects current active settings.

- **startup-config** – Stored in NVRAM; loaded at boot.

To make configuration changes persistent, you must copy the running configuration to the startup configuration.

---

### Copying and Erasing Configuration Files

- `copy running-config startup-config` → Saves the current running configuration to NVRAM (as the startup configuration)
- `erase startup-config`, `write erase`, `erase nvram` + `reload` →  
  - `erase startup-config` → Recommended: erases only the saved startup configuration  
  - `write erase` → Deprecated: older equivalent of `erase startup-config`  
  - `erase nvram` → More destructive: erases all contents of NVRAM, not just the startup-config  
  - `reload` → Must be executed after one of the above to reboot the device and apply the reset
- `reload` → Reloads (reboots) the device, clearing the running configuration **only if it hasn't been saved**
